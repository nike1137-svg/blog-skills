# 내 역할 마무리 (my-role)

글 끝에서 그날의 작업을 **"AI가 한 일 / 내가 판단·검토한 일"**로 나눠 정리한다.
조경호 블로그의 핵심 관점 — "AI가 코드를 쓰고, 나는 어떤 모양의 데이터로·무엇을 택할지 판단한다" — 를 매 글 끝에 심는다.

## 왜 이걸 넣나
- 도구에 실행을 맡기되 **검토 책임까지 넘기지 않는다**는 태도를 남긴다.
- 나중에 읽는 사람(그리고 미래의 나)에게 "무엇을 이해하고 넘어갔는지" 증거가 된다.
- "손으로 한 일은 적어두지 않으면 남지 않는다"는 원칙의 실천.

## 형식
그날 내용에 맞춰 아래 둘 중 하나로:

**표 형태**
```markdown
| AI가 한 일 | 내가 판단·검토한 일 |
|---|---|
| 코드/설정 초안 작성 | 어떤 방식을 쓸지 선택, 결과 직접 확인 |
```

**체크리스트 형태**
```markdown
### 오늘 내가 판단한 것
- [ ] (정규화/인덱스/트랜잭션 등) 왜 이렇게 정했는지
- [ ] 실행 결과를 내가 직접 확인했는가
- [ ] 보안·개인정보에서 최소한만 남겼는가
```

## 규칙
- **자랑이 아니라 판단의 기록**으로 쓴다. "빠르게 했다"보다 "이래서 이렇게 정했다".
- 실수했으면 실수도 한 줄 남긴다(정직한 톤).
- 마지막엔 자연스럽게 **다음 예고 한 문장**으로 넘어갈 수 있게 여지를 둔다.

## 출력
글 하단에 붙일 마무리 블록(표 또는 체크리스트) + 다음 예고 문장 후보 1개.
