# 일상 비유 생성 (analogy-maker)

기술 개념 하나를 받아, 블로그에서 쓰는 것과 같은 결의 **일상 비유**를 만든다.
글 전체를 관통하는 은유(문·상자·기억 등)와 충돌하지 않게 맞춘다.

## 좋은 비유의 조건
- **손에 잡히는 사물/행동**에 빗댄다: 계산대 옆 바구니, 창고, 책 뒤 색인, 레시피, 문과 자물쇠, 상자.
- 개념의 **핵심 동작 한 가지**만 정확히 대응시킨다(너무 많이 갖다 붙이지 않는다).
- 비유가 **어디서 깨지는지**도 한 줄로 덧붙이면 더 좋다(정직한 서술).
- 추상 비유("흐름처럼", "마법같이") 금지. 전문 용어로 전문 용어를 설명하지 않는다.

## 블로그 실제 비유 (톤 레퍼런스)
- 캐시 → "자주 찾는 물건을 **계산대 옆 바구니**에 올려 둠"
- 색인(인덱스) → "책 뒤 **색인**에서 단어 찾듯, 처음부터 안 넘겨도 됨"
- SQL 인젝션 → "레시피에 몰래 한 줄 끼워 넣어 엉뚱한 요리를 시키는 것"
- 배포 터널 → "안에서 밖으로 낸 **터널**, 문은 나만 들어가게 잠금"

## 출력 형식
개념마다:
```
- **비유**: (일상 사물/행동에 빗댄 한 문장)
- (선택) **어디서 깨지나**: (비유의 한계 한 줄)
```
필요하면 후보 2~3개를 주고 고르게 한다.
