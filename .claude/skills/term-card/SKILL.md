# 용어정리 카드 (term-card)

> ⚠️ **먼저 [[lms-safe]]를 적용한다.** 용어 정의·비유·예시를 LMS 원문에서 베끼지 말고, 자체 소화해 내 말로 쓴다(공인 전문용어 자체는 예외). 게시 전 lms-safe 체크리스트 통과.

배운 용어를 조경호 블로그의 고정 3단 템플릿으로 정리한다.
블로그 전 글에서 100% 일관되게 쓰는 형식이므로 **틀을 절대 바꾸지 않는다**.

## 카드 하나의 형식

```markdown
## N. 용어명(English 원어)
- **정의**: 무엇인지 한두 문장. 약어면 원어 풀이를 함께.
- **비유**: 일상에서 바로 떠오르는 비교 하나.
- **예시**: 실제로 어디에 쓰는지 / 주의점 하나.
```

규칙:
- 세 줄은 항상 **정의 → 비유 → 예시** 순서, 이 순서를 바꾸지 않는다.
- 핵심 단어는 `**굵게**` 강조(정의 안의 키워드, 예시 안의 조건 등).
- 비유는 계산대·바구니·창고·메모판처럼 **손에 잡히는 사물**로. 추상적 비유 금지.
- 원어(영어)는 `*이탤릭*` 또는 괄호로 병기.

## 실제 예시 (블로그 원본 톤)

```markdown
## 1. 캐시(Cache)
- **정의**: 자주 쓰는 데이터를 **메모리에 잠깐** 두어 빠르게 꺼내 쓰는 것.
- **비유**: 매번 창고(디스크·DB)까지 안 가고, 자주 찾는 물건을 **계산대 옆 바구니**에 올려 둠.
- **예시**: 로그인 세션 확인. 대신 원본과 잠깐 어긋날 수 있어 **수명(TTL)** 을 정해 둔다.
```

## 여러 개를 묶을 때 (= '오늘의 용어 정리' 글)
- 제목: `"오늘의 용어 정리 — 용어1·용어2·용어3"` (가운뎃점 `·`으로 나열)
- `categories: [일지, 용어정리]`, `tags:`에 각 용어를 그대로
- 카드를 `## 1.`부터 번호순으로 나열
- Front matter는 [[jekyll-frontmatter]] 규칙을 따른다

## 출력
카드(들) 마크다운. 묶음 글이면 front matter + 파일명 `YYYY-MM-DD-terms-주제.md`까지 함께.
